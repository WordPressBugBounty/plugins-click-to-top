== Description ==

<h4>The ultimate scroll to top plugin for WordPress.</h4>
Click to Top is the most advanced <strong>WordPress scroll to top plugin</strong>, designed to improve user experience and navigation on long-content websites. It adds a sleek, customizable <strong>back to top button</strong> to the bottom-right corner of your site, letting visitors instantly return to the top of any page with a single click.

Unlike basic scroll up plugins, Click to Top offers deep customization — choose from 13 scroll icons, 55 hover effects, all 32 jQuery UI easing animations, unlimited colors, and two button styles (square or round). The plugin is fully responsive, touch-friendly, and optimized for performance so it never slows down your site.

Recent updates introduced <strong>custom CSS field</strong> for advanced styling, <strong>smooth scroll anchor links</strong> for same-page navigation, and a <strong>keyboard shortcut (Ctrl + Arrow Up)</strong> for power users. Every feature is designed to reduce bounce rate and keep visitors engaged longer on your content.

Compatible with all major WordPress themes, translation-ready, and backed by an easy-to-use settings panel. Whether you run a blog, magazine, e-commerce store, or corporate site, Click to Top delivers a polished <strong>scroll to top button</strong> experience that users will love.

== Frequently Asked Questions  ==

= What is Click to Top?  =

Click to Top is a WordPress plugin that adds a small button to the bottom-right corner of a website, allowing users to easily navigate to the top of the page with just one click. It enhances the user experience by providing a convenient and efficient way to navigate long pages or articles, reducing bounce rates and contributing to better search engine rankings. The Click to Top button is customizable, and users can choose from different icon styles, sizes, colors, and animations to match their website's design.

= Is Click to Top compatible with all WordPress themes? =

lick to Top is designed to be compatible with most WordPress themes

= Can I customize the appearance of the Click to Top button? =

Yes, Click to Top allows you to customize the appearance of the button to match your website's design. The plugin offers a range of customization options, such as changing the button size, color, shape, and animation. You can also choose from various icon styles, including FontAwesome and Dashicons, or upload your own custom icon. Additionally, Click to Top supports the use of custom CSS for further styling options. By default, the plugin adds a small arrow icon to the button, but you can easily change this to a different icon or text label if you prefer. These customization options make it easy to create a Click to Top button that is both functional and visually appealing for your website's users.

= Will Click to Top slow down my website's loading time? =

No, Click to Top is designed to be lightweight and optimized for performance to ensure that it does not slow down your website's loading time. The plugin uses efficient code and caching techniques to minimize any impact on your website's speed. In fact, Click to Top can even improve user experience and reduce bounce rates by providing a convenient way for users to navigate long pages or articles. However, it is always recommended to use a caching plugin and perform regular speed tests to ensure that your website is loading quickly and efficiently.

## Privacy Policy
Click to Top uses an anonymous telemetry system to collect basic usage data upon user's confirmation. This helps us to troubleshoot problems faster & make product improvements.

The telemetry system **does not gather any data by default.** It only starts gathering basic telemetry data **when a user allows it via the admin notice**. We collect the data to ensure a great user experience for all our users.

The telemetry integration **DOES NOT IMMEDIATELY** start gathering data, **without confirmation from users in any case.**

The data collected may include: WordPress version, PHP version, plugin version, site URL, admin email, server software, locale, and active plugin/theme information. No personal content or sensitive data is ever collected.
